# Domain und E-Mail auf kortekanzlei.com ändern

Alle Vorkommen von `korte-kanzlei.de` werden auf `kortekanzlei.com` umgestellt. Der Kanzleiname `Korte & Partner` bleibt unverändert.

## Änderung

1. **E-Mail-Adressen aktualisieren**
   - `info@korte-kanzlei.de` → `info@kortekanzlei.com`
   - `datenschutz@korte-kanzlei.de` → `datenschutz@kortekanzlei.com`

2. **Betroffene Seiten aktualisieren**
   - Footer
   - Kontaktseite
   - Impressum
   - Datenschutz
   - AGB
   - Haftungsausschluss
   - Blogartikel, in denen die alte E-Mail-Adresse steht

3. **Technische Domain-Verweise aktualisieren**
   - Kontaktformular-Quelle von `korte-kanzlei.de` auf `kortekanzlei.com`
   - erlaubter Host in der Vite-Konfiguration auf `kortekanzlei.com`

4. **Projekt-Memory aktualisieren**
   - Die gespeicherte Domain-Regel wird von `korte-kanzlei.de` auf `kortekanzlei.com` geändert.

- Firmenname: bleibt `Korte & Partner`
